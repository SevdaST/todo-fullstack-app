# To-Do Fullstack App

A simple full-stack To-Do application built with FastAPI, SQLite, HTML, CSS, and JavaScript.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Persistent storage with SQLite
- Frontend connected to REST API

## Technologies

- FastAPI
- SQLite
- SQLAlchemy
- HTML
- CSS
- JavaScript
